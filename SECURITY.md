# Security policy

## Supported versions

There is no stable release yet. Security fixes are developed on the default
branch; no released version is currently supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository when it is
available. Do not report an undisclosed vulnerability in a public issue. If
private reporting is not enabled, contact the repository owner privately
through GitHub before sharing technical details.

Please include the affected commit or release, a concise impact description,
and steps to reproduce. Avoid including real credentials or personal data in
the report.
